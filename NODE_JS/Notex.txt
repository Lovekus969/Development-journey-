What is node js ? 
Node js is runtime environment for the javascript server .
What is REPL?

REPL = Read → Evaluate → Print → Loop

It is an interactive environment where Node.js reads your JavaScript, executes it immediately, prints the result, and waits for your next command.
Node.js is more than the REPL.

Node.js is a JavaScript runtime.

Normally, JavaScript was primarily associated with browsers.

For example:

        Chrome
           ↓
        JavaScript Engine
           ↓
        JavaScript code

Node.js allows JavaScript to run outside the browser:

        Terminal / Server
               ↓
            Node.js
               ↓
        JavaScript

That means JavaScript can interact with things that browser JavaScript traditionally doesn't directly control.

What is a global object?

A global object is an object that provides things that are available throughout the JavaScript environment.
