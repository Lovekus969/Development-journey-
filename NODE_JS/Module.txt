Node.js has two major module systems:

                 JavaScript file
                       |
              ┌────────┴────────┐
              ↓                 ↓
          ES Module          CommonJS
           (Module)        (non-ESM)
              |                 |
           import             require()
           export          module.exports

ES MODULE

Therefore:

          import figlet from "figlet";

works.
