In Express.js, a template is a file that defines the HTML structure of a webpage, where you can dynamically insert data from your server.

Think of it like:

Template = HTML page + placeholders for dynamic data.

1. Why do we need templates?

  Suppose your Express server has a list of users:
  
    const users = ["Kush", "Aman", "Raj"];
    
    Instead of manually creating HTML like:

      <h1>Welcome Kush</h1>
      <h1>Welcome Aman</h1>
      <h1>Welcome Raj</h1>
2. Example using EJS.

EJS TAGS :------

| Tag          | Name                | What it does                                      |
| ------------ | ------------------- | ------------------------------------------------- |
| `<% ... %>`  | Scriptlet           | Runs JavaScript, **doesn't display** result       |
| `<%_ ... %>` | Whitespace Slurping | Runs JS and removes whitespace **before** the tag |
| `<%= ... %>` | Escaped Output      | Displays a value, **HTML-escaped**                |               :Example : <%= 2+4  %> Expected output be 6 
| `<%- ... %>` | Unescaped Output    | Displays a value **without HTML escaping**        |
| `<%# ... %>` | Comment             | Comment for EJS, **not executed/output**          |
| `<%%`        | Literal EJS         | Displays literal `<%`                             |
| `%>`         | Ending Tag          | Ends an EJS block                                 |
| `-%>`        | Newline Slurping    | Removes the newline immediately after the tag     |
| `_%>`        | Whitespace Slurping | Removes whitespace **after** the tag              |
